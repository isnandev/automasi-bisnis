# antislop

Aturan lengkapnya ada di `references/antislop.md` (salinan utuh dari miqdadbadjuber/anti-slop, MIT). Baca file itu **sampai habis** sebelum menulis UI, lalu ikuti aturannya.

Di plugin ini, arah desain sudah ditetapkan oleh `DESIGN.md` di folder kerja. Pakai itu sebagai "design direction" (aturan R-37), jadi tidak perlu bertanya arah desain lagi kecuali DESIGN.md belum ada.
